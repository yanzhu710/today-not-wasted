# 今天没白过

一个纯前端、可离线使用的游戏化生活管理小产品。  
适合直接部署到 **GitHub Pages**，不需要任何构建流程。

## 特性
- 任务 / 习惯 / 快速记录 / 账本 / 日记 / 专注
- 徽章收集、宠物成长、积分与家园系统
- IndexedDB 本地存储
- PWA 支持，可安装到主屏幕
- 支持备份导出 / 导入恢复
- 纯静态部署，适合个人项目展示

## 直接部署到 GitHub Pages

### 方式一：仓库根目录部署（推荐）
1. 新建 GitHub 仓库。
2. 将当前文件夹内的全部文件上传到仓库根目录。
3. 打开 **Settings → Pages**。
4. Source 选择 **Deploy from a branch**。
5. Branch 选择 **main / root**。
6. 保存并等待 Pages 发布完成。

### 方式二：本地预览
不要直接双击 `index.html` 打开，建议使用静态服务器：
- VS Code Live Server
- `python -m http.server 8787`
- 项目内自带的 `serve.ps1` / `serve8788.ps1`

## 目录说明
- `index.html`：入口页面
- `css/`：样式文件
- `js/`：核心逻辑与页面脚本
- `icons/`：PWA 图标
- `manifest.webmanifest`：PWA 描述文件
- `sw.js`：Service Worker

## 技术说明
- 纯 HTML / CSS / JavaScript
- 本地数据存储：IndexedDB
- 路由方式：Hash 路由（适合 GitHub Pages）
- 无后端、无云端依赖

## 当前版本亮点（v2.5.0）
- 伙伴系统完整升级：默认伙伴不再使用固定名字，首次建档由用户自己命名；旧用户会安全迁移到新的单伙伴体系，不清空任何历史数据。
- 四阶段成长统一使用“陪伴值”：Lv.1 初遇期、Lv.2 熟悉期、Lv.3 亲密期、Lv.4 纪念期；Lv.4 需要额外完成加冕仪式。
- 接入 4 阶段 × 8 动作共 32 张正式透明 PNG，摸摸、喂食、玩耍、鼓励、开心、睡觉、庆祝都会使用当前等级对应形态。
- 伙伴页重构为“形态 / 闪卡”双视图；四阶闪卡已经使用 `assets/cards/runtime/` 下的真实 GLB 模型，保留模型厚度与内嵌材质，并支持拖动旋转、点击翻面、缩放、自动漂浮、透视深度和高光强度。运行版只包含 GLB；原始 `.blend` 作为美术源文件由项目方单独保管，不进入 Pages 部署包。
- 增加今日轻状态、喜好发现、伙伴资料、共同回忆、互动每日陪伴值上限和邀请号锁定入口；不加入饥饿、掉心情或陪伴值衰减。
- 商城新增“成长道具 / 加冕果实”。陪伴值达到 720 后才开放兑换，消耗 1 颗完成 Lv.3 → Lv.4 加冕，并解锁最终闪卡。
- 同时包含此前尚未发布的 v2.4.6：生活灵感与徽章筛选收束、Tab 高亮修复、记账算式输入，以及移除“工资 / 奖金”收入分类。
- 保留 v2.4.5 的 Android 原生纵向滚动、窄屏弹窗与声效恢复修复。

## 数据与备份
本项目为**纯本地模式**，数据保存在浏览器的 IndexedDB 中，不上传服务器。

建议：
1. 正式长期使用前，先添加到主屏幕；
2. 定期在“我的”页面导出备份；
3. 若发布新版本后页面未及时更新，可刷新一次，或使用应用内“立即更新”。

## 注意事项
- iPhone / iPad 上建议使用 Safari 并添加到主屏幕。
- 某些浏览器可能在长时间不访问后清理站点数据，因此**备份非常重要**。
- 如果你是作为作品集项目展示，建议保留 `README.md`、`CHANGELOG.md`、`LICENSE` 与 `.nojekyll`。
