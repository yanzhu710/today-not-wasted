# 今天没白过

一个纯前端、可离线使用的游戏化生活管理小产品。  
适合直接部署到 **GitHub Pages**，不需要任何构建流程。

## 特性
- 任务 / 习惯 / 快速记录 / 账本 / 日记 / 专注
- 徽章收集、宠物成长、积分与家园系统
- IndexedDB 本地存储
- PWA 支持，可安装到主屏幕
- 支持备份导出 / 导入恢复
- 纯静态部署，适合个人项目展示

## 直接部署到 GitHub Pages

### 方式一：仓库根目录部署（推荐）
1. 新建 GitHub 仓库。
2. 将当前文件夹内的全部文件上传到仓库根目录。
3. 打开 **Settings → Pages**。
4. Source 选择 **Deploy from a branch**。
5. Branch 选择 **main / root**。
6. 保存并等待 Pages 发布完成。

### 方式二：本地预览
不要直接双击 `index.html` 打开，建议使用静态服务器：
- VS Code Live Server
- `python -m http.server 8787`
- 项目内自带的 `serve.ps1` / `serve8788.ps1`

## 目录说明
- `index.html`：入口页面
- `css/`：样式文件
- `js/`：核心逻辑与页面脚本
- `icons/`：PWA 图标
- `manifest.webmanifest`：PWA 描述文件
- `sw.js`：Service Worker

## 技术说明
- 纯 HTML / CSS / JavaScript
- 本地数据存储：IndexedDB
- 路由方式：Hash 路由（适合 GitHub Pages）
- 无后端、无云端依赖

## 数据与备份
本项目为**纯本地模式**，数据保存在浏览器的 IndexedDB 中，不上传服务器。

建议：
1. 正式长期使用前，先添加到主屏幕；
2. 定期在“我的”页面导出备份；
3. 若发布新版本后页面未及时更新，可刷新一次，或使用应用内“立即更新”。

## 注意事项
- iPhone / iPad 上建议使用 Safari 并添加到主屏幕。
- 某些浏览器可能在长时间不访问后清理站点数据，因此**备份非常重要**。
- 如果你是作为作品集项目展示，建议保留 `README.md`、`CHANGELOG.md`、`LICENSE` 与 `.nojekyll`。
